سرور آنلاین RP RUSH
===================

این سرور موقعیت بازیکن‌ها را از طریق WebSocket ردوبدل می‌کند تا در یک نقشه همدیگر را ببینند.
حساب و رمز همچنان در PlayFab با Title ID برابر 181FA می‌ماند؛ این سرور هیچ رمز یا Secret Key از PlayFab نمی‌خواهد.

راه‌اندازی روی سرویس Node.js:
1) پوشه RP_RUSH_SERVER را در یک مخزن Git قرار بده.
2) یک Web Service از نوع Node بساز و مخزن را وصل کن.
3) Build Command: npm install
4) Start Command: npm start
5) پس از Deploy، آدرس HTTPS سرویس را بردار. برای بازی باید آن را به WebSocket امن تبدیل کنی:
   https://YOUR-SERVICE.example  ->  wss://YOUR-SERVICE.example
6) در بازی RP RUSH روی «آنلاین‌ها» و سپس «تنظیم آدرس سرور» بزن و آدرس wss:// را وارد کن.
7) در مرورگر آدرس https://YOUR-SERVICE.example/health باید JSON با status=online نشان دهد.

تنظیم اختیاری:
MAX_PLAYERS=100
PORT را میزبان به‌صورت خودکار تنظیم می‌کند.

نکات:
- این نسخه، سرور پایه حضور و موقعیت زنده است؛ هنوز ضدتقلب، ذخیره دائمی موقعیت و اعتبارسنجی هویت PlayFab در سمت سرور ندارد.
- شناسه ارسالی از کلاینت به‌تنهایی اثبات هویت نیست؛ برای انتشار عمومی باید احراز هویت سمت سرور اضافه شود.
- برای اتصال از اینترنت موبایل، از wss:// استفاده کن؛ ws://localhost فقط برای تست روی همان دستگاه/کامپیوتر است.
